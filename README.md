# やることリスト

**8/20 講座「はじめての Git・GitHub」の練習用サンプルです。**

## これは何？

やることを書いて「追加」を押すと、下に並ぶだけの小さなページです。
チェックを入れると取り消し線がつき、ブラウザを閉じても消えません。

## 開き方

`index.html` を**ダブルクリック**するだけです。インストールも準備も要りません。

## 自由に壊してください

このリポジトリは**練習用**です。中身を書き換えても、消しても、まったく問題ありません。

壊してしまっても、元に戻せます。それを体験するためのサンプルです。
講座では、実際にわざと壊してから元に戻すところをお見せします。
